# Проблемы

| Проблема                                                    | Описание                                                                               |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Клиентский интерфейс оператора работает с DWH напрямую      | Вероятность испортить данные, скомпроментировать данные                                |
| Нет системы аутентификации и разделения ролей пользователей | У всех одинаковые права пользователей                                                  |
| Медленная и устаревшая система для DWH                      | Текущая система на базе SQL Server 2008 морально устарела и не справляется с объёмами. |
| Устаревшая шина данных                                      | Apache Camel в текущей реализации недостаточно масштабируема и требует обновления.     |
| Разрозненные данные                                         | Нет централизованной модели данных, сложность интеграции новых бизнесов.               |
| Ограничения Power Builder                                   | Ограниченные возможности для масштабирования и гибкости.                               |
| Отсутствие самообслуживания                                 | Отчёты создаются вручную, что замедляет работу.                                        |
| Сложная интеграция новых систем                             | Подключение новых компаний требует значительных усилий из-за кастомной бизнес-логики.  |




# Приоритизация проблем

## MoSCoW

| Категория | Проблема                                                    | Обоснование                                                              |
| --------- | ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| Must      | Медленная и устаревшая система для DWH                      | Блокирует реализацию витрины и масштабирование аналитики.                |
| Must      | Разрозненные данные                                         | Усложняет интеграцию новых бизнесов и снижает прозрачность.              |
| Must      | Отсутствие самообслуживания                                 | Ключевая цель проекта.                                                   |
| Should    | Устаревшая шина данных                                      | Повышение масштабируемости и надёжности интеграции.                      |
| Should    | Ограничения Power Builder                                   | Устаревшая технология требует обновления для оптимальной работы системы. |
| Could     | Нет системы аутентификации и разделения ролей пользователей | Важно для долгосрочной надёжности, но менее критично для первых этапов.  |
| Could     | Клиентский интерфейс оператора работает с DWH напрямую      | Важно для долгосрочной надёжности, но менее критично для первых этапов.  |
| Won’t     | Сложная интеграция новых систем                             | Можно решить позже при внедрении новых инструментов.                     |
